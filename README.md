# Gambling Galaxy

Un jeu incrémental de tickets à gratter dans l'espace, en pixel art.

- Gratte des tickets pour gagner des crédits (CR) et acheter des tickets plus chers.
- 5 tickets aux règles différentes : Poussière d'Étoile, Code Alien, Trou Noir, Grande Ourse, Supernova.
- Améliorations : laser de grattage, drones gratteurs, météorite porte-bonheur, pilote automatique.
- Prestige : échange tes gains contre des étoiles dorées (+25 % sur tous les gains par étoile).

## Jouer

Ouvre `index.html` dans un navigateur. La partie est sauvegardée automatiquement dans le navigateur.
